## 1. Purpose & Scope
Defines the prioritized **V1.5 ("Trust & Reach")** feature backlog, combining:
1. Features explicitly deferred from `v1.0 MVP` in `A2` §7 Roadmap (`FR-014`–`FR-019`, background service, SQLCipher, optional Python/OCR runtime, 2D graph).
2. High-leverage UX, developer, and digital-twin differentiators identified during architectural review that build directly on `B4 v2.3` with minimal infrastructure risk.

**Excludes (remains V2.0+):** Autonomous `Auto` execution, Plugin SDK & marketplace (`FR-016`), Multi-device encrypted sync (`FR-020`), Cloud-LLM opt-in, PostgreSQL multi-writer cutover (`B4` §4.5), and Ed25519 signed audit checkpoints (`B6` §7).

**Audience:** Product Management, Rust/Frontend Engineering, Design, Security, QA.

## 3. Feature Specifications & Acceptance Criteria

### `V1.5-01` — Quarantine Space vs. Freed Space UI & Soft Quota *(Promoted to v1.0 MVP)*
- **Status:** **Promoted to v1.0 MVP** — zero-DDL implementation tracked in `A2` `FR-012/013`, `C1 v1.2` (`quarantine.space_summary`), and `D3` §5.
- **Problem:** Per-volume quarantine (`ADR-003`) performs `O(1)` same-volume renames, so OS free disk space does not immediately rise after "deleting" duplicates.
- **Specification:**
  - Dashboard & Disk Rescue split metrics into **`Staged in Quarantine (Reversible, 30d)`** vs. **`Actually Freed on Disk`**.
  - One-click **"Empty Quarantine Now"** triggers `quarantine.purge(..., confirmedPermanent=true)` with explicit byte-reclaim confirmation.
  - Soft quota (`settings['quarantine.max_volume_pct']`, default `10%`): warns user if quarantine exceeds threshold or volume free space drops `<10%`.
- **Acceptance Criteria:** Quarantining 10GB shows `10GB Staged (0GB Freed yet)`; purging updates OS free space and sets `quarantine_entries.purged_at`.

### `V1.5-02` — "Why Didn't It Match?" Search Diagnostics
- **Specification:** `search.query` returns a `diagnostics` block alongside `results`:
  `{ skipped_perm_roots: number, placeholder_matches: number, quarantined_matches: number, offline_volume_matches: number }`.
- **UI:** When `results.length < 5`, render non-intrusive diagnostic chips (e.g., *"2 filename matches are in Quarantine [Include]"* or *"1 match is on offline drive `Archive_2025`"*).
- **Acceptance Criteria:** Searching for a quarantined filename returns 0 active hits and `quarantined_matches = 1` without leaking quarantined content snippets (`B6` §2).

### `V1.5-03` — Offline External-Drive Search & Drive Parity Diff
- **Specification:**
  - Preserve `files`, `chunks`, and `qdrant` points when `volumes.status = 'offline'`; display offline badge + `"Connect <mount_point> to open"` in Search (`FR-007`).
  - Add **`volumes.parity_diff(sourceVolumeId, targetVolumeId)`** comparing `blake3` sets across any two indexed volumes to list files present on `source` with zero copies on `target` (excluding `.aegisignore` & `quarantine`).
- **Acceptance Criteria:** Unplugging an indexed USB drive preserves searchability; Parity Diff accurately identifies unique unbacked-up files within `<2s` for 200k files.

### `V1.5-04` — CLI (`aegis`) & Loopback REST/GraphQL (`FR-014`)
- **Specification:** Expose `aegis search`, `aegis scan`, `aegis dedupe`, `aegis health`, `aegis actions approve`, `aegis doctor` over local IPC/loopback `127.0.0.1:4777` authenticated via rotating OS-keychain bearer token (`B6` §2).
- **Acceptance Criteria:** CLI and Desktop share identical `C4` Policy Engine gates; non-loopback bind attempts or missing tokens return `401/403` (`B6` §8).

### `V1.5-05` — Background Service, Global Hotkey & OS Context Menus
- **Specification:** Optional tray/daemon mode keeping `notify`/USN/FSEvents watchers active when UI window is closed; OS-level global search shortcut + Explorer/Finder `"Inspect with Aegis"` context menu.
- **Acceptance Criteria:** Idle background RSS remains `≤350MB` (WebView unloaded, `aegis-llm-worker` evicted).

### `V1.5-06` — Smart Collections (`FR-015`)
- **Specification:** Saved live queries (`collections` table) rendered as virtual folders in Files/Browse (e.g., *"Unreviewed Secrets"*, *"2026 Tax Statements"*, *"Offline Archive Media"*).
- **Acceptance Criteria:** Creating, editing, and deleting a Smart Collection never mutates underlying filesystem paths; query refreshes incrementally on `IndexUpdated` events.

### `V1.5-07` — Developer Build-Cache Reaper & `.gitignore` Secret Escalation
- **Specification:**
  - Extend `playbook.disk_rescue()` (`cache_dirs` in `B4 v2.3.1`) to scan `atomic_units` (`git_repo`, `node_pkg`, `rust_crate`, `python_pkg`) for `node_modules`, `target/`, `.venv/`, `.gradle/` where `max(source_mtime) > 60 days` ago.
  - Cross-check `security_findings` paths inside Git repos against `.gitignore`: multiply `context_risk_score` by `1.5×` (capped at `100.0`) if untracked/unignored or detected in `HEAD` commit files.
- **Acceptance Criteria:** Dormant `node_modules` cleanup never touches source files (`ADR-004` respected via `C4 v1.1` §3.3's explicit `safe_build_cache` carve-out for registered `cache_dirs`); unignored `.env` ranks above ignored `.env`.

### `V1.5-08` — Opt-In Encryption at Rest (SQLCipher + Encrypted `qdrant-edge`)
- **Specification:** Passphrase → `Argon2id` → DEK stored in OS Keychain (`B6` §2); converts `aegis.db` via SQLCipher re-key. Because `qdrant-edge` relies on `mmap` to stay within the desktop RAM budget (`B1/B2` §3), encrypted vector shards require either placing the shard directory inside an OS-level encrypted container/volume (retaining `mmap`) or disabling `mmap` behind a custom encrypted block wrapper with an explicit higher-RAM tradeoff warning.
- **Acceptance Criteria:** Without unlocked OS keychain / passphrase (and unlocked shard container when enabled), reading `aegis.db` or vector files yields `0` plaintext filenames, chunks, or entities.

### `V1.5-09` — Dropzone "Inbox Zero" Watchfolders & Deterministic Filename Hygiene
- **Specification:** Users mark `~/Downloads` or `~/Desktop` as a **Dropzone**. Incoming files accumulate into a scheduled Simulator batch pairing deterministic **Filename Hygiene** rules (strip `(1)`/`Copy of`, normalize `YYYY-MM-DD` dates) with `Curator` destination suggestions (`C4`).
- **Acceptance Criteria:** Dropzone never auto-moves files in V1.5; user approves/graduates patterns in 1 click via `D3` Flow 2.

### `V1.5-10` — Storage Analytics (`FR-018`)
- **Specification:** Interactive treemap by folder/file-type/project, 30-day growth deltas from `files.first_seen` + `size`, and `"What changed this week"` view.
- **Acceptance Criteria:** Treemap sums match hardlink-adjusted disk usage (`ADR-003`).

### `V1.5-11` — Scoped / Filtered Undo (`FR-012`)
- **Specification:** Add `undo.query(filter: { pathPrefix?: string, afterTs?: number, origin?: string })` returning matching executed `action_batches` for selective rollback through `FR-005.4` Pre-Rollback Reconciliation.
- **Acceptance Criteria:** Rolling back filtered moves inside `~/Documents/Tax` leaves unrelated batches untouched and honors `C1` §4 conflict dialogs.

### `V1.5-12` — Broken-Link Guard in Simulator
- **Specification:** During `actions.simulate(batch)`, inspect `B4.relationships` (`rel_type = 'references'`) for relative Markdown/LaTeX/code links pointing to or from moved files; display warning badge *"Breaks N relative links"* in Simulator (`D3` §3).
- **Acceptance Criteria:** Moving a `.md` referencing `./assets/diagram.png` surfaces an explicit warning before approval.

### `V1.5-13` — 2D Interactive Knowledge Graph Viewer
- **Specification:** Force-directed 2D canvas over `graph.neighborhood(entityId, depth=2)` filtering by entity type, project, and relationship weight; clicking nodes opens file preview or refocuses neighborhood.
- **Acceptance Criteria:** Smooth 60fps interaction up to 500 visible nodes; `<50ms` backend query (`FR-003.1`).

### `V1.5-14` — Scheduled Housekeeping & Quiet Digest (`FR-017`, `FR-019`)
- **Specification:** Local scheduler (`schedules` table) runs weekly dedupe/cache scans and surfaces a single quiet digest banner (new dupes, open security findings, health score delta). Quiet by default (no OS toast spam).

### `V1.5-15` — Optional Lazy Python / OCR / Whisper Runtime (`ADR-001`)
- **Specification:** On-demand download of sandboxed OCR / `faster-whisper` / `.pst` parser bundle (verified via Ed25519 manifest + `SHA-256`, `E2` §2) strictly for users who opt into `FR-002.3` or `FR-001.7`.

### `V1.5-16` — Built-in Domain Modes (Developer / Research / Trader)
- **Specification:** Pre-plugin domain presets adding:
  - *Developer:* Dependency map + dead-repo (>180d) dashboard.
  - *Research:* Local DOI/arXiv/BibTeX extractor + preprint-vs-published `version_of` linking.
  - *Trader/Admin:* **Missing-in-Sequence Detector** flagging missing months/quarters in recurring statement series (e.g., `Brokerage_Jan..Oct, Dec` → flags missing `Nov`).

### `V1.5-17` — i18n Framework, Cross-Platform Parity & LLM Sandboxing (`FR-022`, `OQ-03`, `OQ-15`)
- **Specification:** Externalize UI strings (`i18next`), complete macOS/Linux watcher & packaging parity (`OQ-03`), and confine `aegis-llm-worker` inside OS-native sandboxes (Windows AppContainer, macOS Seatbelt, Linux `seccomp-bpf`).
