## Architecture & North-Star Rules

- **K1 (Propose, approve, undo):** Every ratifiable CDO recommendation (`CreateFolderlessRule`, `CreatePrivacyRule`, `AdjustSetting`) executes only on explicit owner ratification (`ratify_cdo_recommendation`), stores an exact undo snapshot in `cdo_ratifications`, and supports single-click `undo_cdo_ratification`. Workspace file remediations navigate to each capability's `K1` review screen (`NavigateToScreen`). Triage state (`open`, `ratified`, `snoozed`, `dismissed`) persists in `cdo_recommendation_state`.
- **K2 (30-day quarantine):** Every CDO query filters `f.deleted_at IS NULL AND f.state NOT IN ('quarantine', 'missing')`. The CDO agent never deletes files.
- **K3 & R9 (Local only):** Pure-Rust synthesis with zero networking crates in `aegis-core`, `aegis-embed`, or `aegis-llm`.
- **K4, R5, R11 (Disk-only, zero telemetry):** Synthesizes solely from saved disk files, catalog tables, Folderless/Governance rules, Health Breakdown, Knowledge Graph, Self-Healing, and Cross-Project reports — never screen capture, keystroke logging, or active window tracking. Excludes `backup`-role volumes (`COALESCE(v.role, 'unassigned') != 'backup'`).
- **K5 & R4 (On-demand LLM):** Deterministic executive scoring, bottleneck diagnosis, and proposals run without loading any ML model. Optional `cdo_synthesize_briefing` runs `OnDemandLlm` off the SQLite lock guarded by `state.rag_running` and caches snapshots in `cdo_briefing_snapshots`.
- **R6 (Visible rules):** Invoice/inbox friction proposals compile editable `FolderlessRuleInput` rules via `folderless::compile_intent_deterministic`.
- **R7 (Sensitive isolation):** `confidential`/`secret` files are excluded from evidence paths and LLM briefing prompts unless Windows CredUI unlock (`reveal_sensitive`) is active (`include_sensitive = true` when locked returns `PermissionDenied`).
- **D1 (Encrypted storage):** Migration `0018_cdo_agent.sql` stores all CDO state inside SQLCipher-encrypted `aegis.db`.
